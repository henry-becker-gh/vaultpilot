# Devnet deployment status — environmental blocker (recorded 2026-09-17)

## Status

- Program **built** (`target/deploy/vaultpilot.so`, 131 992 bytes) and **verified end-to-end
  on a local Agave v2.1.21 test-validator**: 6/6 integration checks pass (`docs/TESTING.md`).
- Program is **not yet deployed to public devnet** for one reason only: the build container's
  shared egress IP has the devnet faucet's free quota exhausted. This is an infrastructure
  limit, not a code or toolchain problem.

## Consequences

- `scripts/devnet-demo.sh` is **header-gated** now: it checks
  `x-ratelimit-airdrop-remaining` first, makes at most ONE request per key, skips funding
  if the key is already funded, and aborts cleanly instead of hammering.
- Deployment from any IP with faucet quota is a single command:
  ```bash
  ./scripts/devnet-demo.sh   # fund -> build+deploy -> initialize -> 2 deposits -> docs/DEVNET_EVIDENCE.md
  ```
  Budget: ~3–4 faucet SOL (program rent ≈0.92 SOL + buffer, two demo deposits 0.1 + 0.333 SOL).
- Nothing else in the project depends on the public devnet deployment: the dashboard reads
  whatever chain the configured RPC points at, and the demo flow is identical on a local
  validator.

## Honesty note

We will never present local-validator runs as devnet transactions. Until
`docs/DEVNET_EVIDENCE.md` exists (generated by the script above with real signatures),
this repo claims: **built + tested on a live local validator, devnet deployment pending
faucet availability.**
